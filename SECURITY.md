# Security Policy

## Reporting a Vulnerability

Report security vulnerabilities by emailing the maintainer at **security@ryasai.com**.

- **Do not open public GitHub issues** for security reports.
- Acknowledgement within 48 hours.
- Critical vulnerabilities fixed within 7 days; lower severity on a best-effort schedule.
- Include reproduction steps, affected version, and impact assessment in your report.

## Scope

This policy covers the application source code in this repository only. Vulnerabilities in third-party dependencies should be reported to their upstream maintainers.

## Supported Versions

Only the latest `0.4.x` release line receives security fixes.
